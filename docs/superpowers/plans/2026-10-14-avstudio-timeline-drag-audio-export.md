# AVStudio Timeline Drag, Audio, and Export Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Execution requires subsequent user authorization; no execution method is selected by this planning request.

**Goal:** Extend the existing editor with frame-accurate placement and overwrite, editable detached/replacement audio, continuous audible preview through edits, and MP4/MOV/WAV/MP3 delivery from one validated composition.

**Architecture:** Extend immutable occurrence snapshots and the source registry, with pure frame-window and audio-ownership projections shared by editing, preview, and serialization. Keep transport mappings, media leases, decoder readiness, and Web Audio nodes outside history. Add a strict Version 3 compiler alongside unchanged Version 1/2 handling; reuse the bounded FFmpeg worker to build selected picture and one PCM16 master, then publish validated artifacts atomically.

**Tech Stack:** Existing React 19/TypeScript/Vite, Vitest/Testing Library, Playwright with installed Edge; Python/FastAPI/pytest/ruff; installed FFmpeg/FFprobe; browser HTMLMediaElement/Web Audio; Python and Node standard libraries for media verification.

**Spec:** [Approved design](../specs/2026-10-13-avstudio-timeline-drag-audio-export-design.md). The advanced-timeline foundation applies where that design does not supersede it. The user's 2026-10-14 approval supersedes the design file's historical proposed-status text; do not edit that file as part of planning.

## Global Constraints

- This request authorizes **this plan file only**. Do not implement application code, run implementation tasks, install packages, change configuration, commit, push, or deploy.
- Future execution must use existing installed dependencies; no package/lock/configuration/system-setting changes or FFmpeg/encoder installation. No database, authentication, collaboration, deployment, desktop conversion, transitions/effects, ProRes, additional PIP tracks, per-segment volume, or separate export-retry service.
- Supported project FPS: `24, 25, 30, 50, 60`; clip speeds: `1, 0.75, 0.5`; source trims remain inclusive. New normalized output windows and ownership intervals are half-open. Round nonnegative project positions half up.
- `L = max(1, floor(((source_end - source_start + 1) / source_fps / speed) * F + 0.5))`; a visible window has duration `output_out_frame - output_in_frame` and must lie in `[0,L)` with an exclusive end at most L.
- Audio: `48000` Hz, stereo; `K = 48000/F`; final duration is `N/F`, picture is exactly N frames, master is exactly `N*K` samples. Accept independent/music source EOF shortfall **strictly less than K**, reject shortfall at least K. Never loop sources or freeze the last frame/sample to extend content.
- Picture priority: Video 2, then Video 1; composite existing PIP, then image. Audio priority: independent audio, then the picture owner's linked original, then silence; mix music additively. PIP sound is excluded. Apply each existing gain/mute bus once; preserve gain range `0..1` and defaults `1` original / `0.3` music.
- “Preserve the existing 30-entry history and atomic validation before restoration.” Files, URLs, playback/AudioContext state, mappings, candidates, and jobs stay outside snapshots.
- Preserve current Settings and all byte/queue/timeout/retention bounds. External audio catalog is at most `max_clips`; combined independent/music segments at most `10 * max_clips`; their external uploads share the existing audio-file byte budget. Manifest budget is `64 KiB`; identifiers are at most `128 UTF-8 bytes`. Do not raise configuration values.
- Video 1 defines final duration and must contain at least one frame, including audio export requests. Audio tails may extend beyond N in the editor but are clipped on export. Video 2 must fit inside `[0,N)` and cannot overlap; touching edges are valid.
- Preserve legacy absent-version/Version 1 and Version 2 uploads, corrections, MP4 routes, and response shapes. Legacy Version 1 looping remains isolated; Version 2/3 music never loops.
- MP4 is mandatory: H.264 `medium`, CRF `23`, `yuv420p`, AAC `192 kb/s`, 48 kHz stereo, faststart. MOV copies final MP4 H.264/AAC streams, with explicit mapping and faststart. WAV is the final PCM16 master. MP3 uses installed `libmp3lame`, `320 kb/s`, 48 kHz stereo, Xing/gapless metadata.
- `Ctrl+Alt+L` detaches only an eligible selected video; preserve `Ctrl+L`. Preserve Undo/Redo/Delete/Backspace guards for text editing, IME, repeat, dialogs, gestures, and locks. Tools remain outside clip lanes, including at narrow widths.

## Review Focus

1. A candidate finishes loading after Undo, another placement, or New Project: revalidate current state, reject stale sessions, release only candidate leases, preserve Redo (Tasks 5–6).
2. Several fragments share one source, or only detached audio still references a deleted video: preserve its File/URL, frozen recipe, and deduplicated upload until all owners release it (Tasks 1, 4–5, 10, 12).
3. FPS conversion shrinks one-frame windows, creates touching-to-overlap rounding, or crosses the exact K-sample EOF threshold: reject atomically without moving stacks, selection, or sound offsets (Tasks 3–5, 12).
4. User Pause/newer edit arrives during real source readiness, autoplay rejection, or a late `play()` promise: cancel stale resume, preserve truthful Preparing/Resume Audio/error state and bounded voices (Tasks 8–9, 17).
5. Optional export fails or cleanup runs while extras are encoding: keep valid MP4, serve no partial extra, retain processing exclusion until all requested artifacts are terminal (Tasks 14–16, 18).
